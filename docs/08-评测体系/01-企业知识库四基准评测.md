# 企业知识库四基准评测

企业知识库的公共评测由四套数据组成，不再使用与产品目标不一致的百科检索、个人记忆和通用多跳数据。

## 能力映射

| 数据集 | 系统链路 | 关键指标 |
|---|---|---|
| FinanceBench | PDF 解析 → Root/Leaf → 检索 → 回答 → 引用 | Recall、MRR、答案 F1、引用 P/R |
| TAT-QA | 表格/正文解析 → 混合检索 → 数值推理 | Evidence Recall、EM、F1 |
| CRUD-RAG | 中文检索 → 问答/摘要/幻觉识别 | Recall、答案 F1、支持性 |
| ViDoRe V3 | 页面图片/Markdown → 视觉检索 → 页码/BBox | Page nDCG、BBox IoU、引用 P/R |

公共集用于模型和检索策略 A/B；RBAC、版本更新、删除同步、内部术语和跨租户泄漏仍必须由企业私有 Gold Set 验收，公共集不能替代这些安全测试。

## 统一数据契约

所有 loader 输出 `BenchmarkBundle`：

- `cases` 保存问题、参考答案、Gold source IDs、场景和可选 BBox。
- `corpus` 保存可导入知识库的文本、表格或页面。
- prediction 保存系统实际召回 source、引用 source、答案和可选预测 BBox。

统一契约保证四套数据复用同一个计分器，避免每套 benchmark 的指标口径不同。

## 回归纪律

1. 固定数据 revision、样本和 seed。
2. 每次只改变一个检索变量，例如 rerank 或 Root/Leaf。
3. 同时报告质量、P95 延迟和成本。
4. 引用和权限属于硬门槛，不能用回答平均分抵消。
5. 英文公共集不得翻译后与原榜单横向比较。

具体命令与数据许可见 `api/eval/README.md`。
